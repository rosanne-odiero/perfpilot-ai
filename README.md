# PerfPilot AI

> AI-powered code optimization backed by real profiling and reproducible benchmarks.

PerfPilot AI audits a whole Python repository for performance risks, then lets you take one hotspot
further: profile it, generate an optimization, check that the behavior is unchanged, and benchmark it.
Every number in a report is labeled by where it came from: **measured**, **static analysis**, or
**AI hypothesis**.
